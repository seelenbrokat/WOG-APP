Create printer

  1. In the title action bar, click on the action Create printer. The Printer Editor opens.
  2. In the General section, enter the name, printer language, paper source, and orientation.
  3. In the Connection Type section, set the technical connection for the printer:
    • Local Viewer: The output is made to the program stored for PDF documents.
    • Bluetooth: The printer is accessible via Bluetooth from the user's PC.
    • OS: OS stands for Operatingsystem (operating system). The connection to the printer is established through your operating system.

Delete printer

In the Action bar in the printer editor, click the Delete action. This will only make the printer inactive and it can be restored.

Restore Printer

  1. Remove the **Active" filter from the printer list and search for the printer.
  2. Click on the link, the printer editor will open.
  3. In the action bar on the right, select Restore.

The printer is now active again and can be used in all other functions.
