Data Transfer Configuration

In the Interface Cockpit you can see the list of all active and inactive carrier connections of the system. In this screen, you can check the communication of active connections and configure carrier interfaces.

Set up freight carrier connection

  1. Click on the wrench symbol next to the name of the desired carrier. The corresponding Interface Configuration opens.
  2. In the header, you can specify whether the carrier connection is set up across systems or across clients or whether you want to restrict this connection to a specific system or client.
  3. Enter the connection data provided by the carrier in the appropriate fields.
  4. Save the configuration by clicking on Save and close the configuration window. The freight connection is now active.

Check freight forwarder communication

If it is an active interface, click on the name of the respective carrier to open the corresponding Task Manager. In the Task Manager the communication history of the interface can be checked. The Actions button in the lower left area of the mask can be used to add a status to a task, to adjust the recipient of a task, or to repeat selected tasks.
