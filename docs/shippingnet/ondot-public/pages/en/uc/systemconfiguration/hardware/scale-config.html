KERN DE – Platform Scale Setup

Prerequisites

Important

For serial connections (COM scale), only an original KERN cable may be used. Standard RS232 cables are not supported and will cause communication errors.

Reset to Factory Settings (optional)

If the scale was previously configured differently, it is recommended to perform a factory reset before setup. Please refer to your KERN scale's manual for the exact procedure.

Install USB-RS232 Adapter (optional)

This step is only required if your PC does not have a native COM port.

Newer Adapters (Windows Update)

Newer USB-RS232 adapters can be installed directly via Windows Update. Windows will detect the adapter automatically and install the appropriate driver.

Older Adapters (Prolific PL2303)

Older adapters using the Prolific chipset are recognizable by their characteristic housing. These devices require a manual driver installation:

  1. Download the driver: PL2303_Prolific_DriverInstaller_v1.12.0.zip
  2. Extract the ZIP file.
  3. Run PL2303_Prolific_DriverInstaller_v1.12.0.exe and complete the installation.

Test the Scale

Before configuring the scale in shippingNET, verify the connection using PuTTY.

  1. Open Device Manager and look under Ports (COM & LPT) for the entry Prolific USB-to-Serial Comm Port. Note the assigned COM port (e.g. COM3).
  2. Download and launch PuTTY: putty.exe
  3. Set the connection type to Serial, select the noted COM port, and click Open.
  4. Press the S key in the PuTTY window. The scale should respond with the current weight reading.
Tip

If the scale does not respond, check the baud rate in the scale settings and make sure PuTTY uses the same baud rate (KERN default: 9600 Baud).

Install the shippingNET Client

The shippingNET Client enables direct communication with non-network devices such as the KERN scale.

The full installation guide is available here: How to access shippingNET – shippingNET Client

Configure the Scale in shippingNET

Select the Scale

  1. Open System Configuration in shippingNET.
  2. Navigate to Device Configurations.
  3. Select KERN DE – Platform Scale as the device type and assign the corresponding COM port.
  4. Save the configuration.

Open and Test the Shipping Station

  1. Switch to the Shipping Station.
  2. Place a test object on the scale.
  3. Verify that the weight displayed in shippingNET matches the reading on the scale's display.

Periodic Weight Reading

The periodic weight reading feature allows shippingNET to automatically poll the scale at a configurable interval. Enable this option in the dispatchstation to ensure continuous weight transfer without manual triggering.
