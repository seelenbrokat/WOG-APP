Shipment Transfer

  1. Before setup, a cross-departmental setting in the Interface Cockpit in the FedEx item, the parent username and parent password must be stored. (This can be requested from ondot Support.)
  2. In the Department Setting the customer number in the externalsystemID 1.
  3. After saving the department settings and the carrier, click on Registration in the action bar in the Carrier Editor
  4. Select the department for which the registration is to be carried out
  5. Read and confirm the EULA
  6. Select a verification method and enter the appropriate verification code.
  7. After confirming the code, the carrier is set up for these departments, as well as those below.

Status download

The status download is automatic for all registered departments

Data transfer

Data transfer happens automatically when a label is printed. It is possible to cancel a transferred shipment via cancellation of the shipment.
