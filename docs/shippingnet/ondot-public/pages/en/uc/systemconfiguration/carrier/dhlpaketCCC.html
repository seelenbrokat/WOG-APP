DHL Parcel CCC

Configuration

Shipment Transfer

  1. Activate the carrier in the Department Setting for the desired department.
  2. Store the API access data (ClientID, Clientsecret, Account Number) transmitted by the carrier in the Interface Cockpit in the entry DHL Paket CCC.
  3. Also enter the 2-digit country code (e.g. "CZ" for Czech Republic) of the country from which the shipments are sent.
  4. If the customs documents are to be created electronically by the DHL web service, select "Yes" in Generate customs document.

Status download

The status download is done automatically for all departments in which the carrier is activated and configured.

Data transfer

Data transfer happens automatically when a label is printed.

Update of access data

Once a year, the access data for the DHL Parcel CCC API must be updated. For this purpose, new access data will be sent to the stored e-mail address of the customer account - you will receive an e-mail with ClientID and PDF decryption password and one with an encrypted PDF file containing the new client secret. You can decrypt and open the transmitted PDF file with the client secret with the password from the first mail.

The old access data in the interface cockpit must be exchanged for the new ones (this applies to ClientID and Clientsecret - the account number remains unchanged). The entry to be changed can be identified either by the name of the client/department or by the stored account number.

After receiving the first mail, a change period of 30 days starts in which both the old and the new access data can be used to create a shipment - 7 days before the end of the period, another reminder will also be sent out by DHL.

After the end of the switching period, the shipment creation with the old access data no longer works.
