Subject type

If you create a compartment in Warehouse Modeling, a compartment type must also be selected for the compartment.

Among other things, the dimensions (width, height, depth) as well as the maximum load weight or a third-party system ID are stored on a compartment type.

The settings on the compartment type are subsequently relevant for many processes in the warehouse.

General Settings

  • **Name 😗* Use the names to identify your subject type. The name is displayed in drop-down lists during warehouse modeling in order to be able to store it on the tray.
  • **Warehouse technology 😗* You can use warehouse technology to address automated warehouses such as Lean-Lift or AutoStore.
  • **Dimensions 😗* The geometric dimensions are important for finding a free space in the warehouse. You can use it to determine which items fit into the compartment.
  • **Max. load weight 😗* With the max. load weight, you determine how many kg of goods can be stored on the compartment.
  • **Max. weight per box 😗* With the max. weight per box, you determine how heavy a container or box may be in order to be allowed to store it in this compartment. If, for example, you want to store containers heavier than 15 kg further down for safety reasons, you can define a compartment type that has exactly this setting.
  • **Free space determination 😗* Is a drop-down field ...
  • **Third-Party SystemID 😗* The Third-Party SystemID is for communication with third-party systems, such as a merchandise management system.

Storage Location Usage and Storage Features

With the bin usage and the storage properties, you determine the use of the bins on the tray.

The settings made are automatically transferred to the compartment when the compartment type is selected.
