Jobs

The job list shows all jobs for the Task Manager clearly in the usual list view.

Working with Lists gives more information about how to use the list view.

By clicking on the plus sign, you can create a new job.

The following fields are mandatory:

  • Name is an input field for the job name and serves to uniquely identify the job.

  • Category is a drop-down field with the following values:

    • Export (Used for data export jobs)
    • Import (used for data import jobs)
    • Maintenance (Used for jobs that start periodically on a schedule.)

  • Trigger is a drop-down field with the following values:

    • File storage (Your directory is monitored and if a file is created, the job is triggered) With the selection, the new field "File filter printout" is displayed. The "File Filter Expression" is used to identify the correct file in a directory.
    • Manual (Must be done manually in shippingNET
    • Schedule (Starts automatically according to a defined schedule.) With the selection, new fields for schedule creation appear.

  • Task Type is a drop-down field with the following values:

    • File Download With the selection, additional fields are displayed for the connection to a server and the download configuration. If the download is successful, further processing processes can then also be started automatically. (follow-up task & integration script)
    • Integration Script: With the selection, an additional field for the Integration Script selection is displayed.
    • Standard Function: With the selection, an additional drop-down field for the Standard Functions selection is displayed.

The following input fields for the job configuration are not mandatory:

Fields for error handling:

  • Pause After an error, the script is tried to run again. The number field "Pause" is used to set the number of seconds after the script is executed again. The default value is 60 seconds.

  • Number of Attempts this field defines the number of times the job is attempted again without errors after an error. The default value is 3.

Notification settings fields:

  • In case of error
  • If successful

Both fields are drop-down fields. When the value is changed from "No notification" to "Individual", fields will appear to enter email addresses. The list of stored email addresses will then be informed by email about the status of the last run, depending on the error or success.
