Release Notes from shippingNET

As a rule, we create a major release (stablelabel) of shippingNET.

A 4-digit version number is used to identify the label.

26. 1. 0. 0 → year . Stablelabel . intermediate label . Hotfix

  • intermediate labels are used to store features between the stablelable cycles in shippingNET.
  • Hotfixes are used to quickly fix urgent bugs in shippingNET.

You can find out which version is currently installed on your server at the bottom right of the login page.

The individual release notes are available as a menu item.
