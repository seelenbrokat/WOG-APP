Resources for Developers and Integrators

The content of this section is intended for developers and integrators. Learn here how to save data with shippingNET or customize labels and documents.

Exchange data

Public API

The Public API of shippingNET is a state-of-the-art web API in REST architecture ("Representational State Transfer"). It provides you with an interface for importing articles, Colli, orders and shipments. The services also include methods to export data to the above objects.

For more information, see Public API.

Integration Scripting

If you have data in a different format, you can use the integration scripts to convert data and import it into shippingNET.

The scripts also offer you many options for exporting data. For more information, see Integration Scripting.

Customize Documents

shippingNET comes with a variety of standard documents. You can activate these standard documents in System Configuration. See also Creating Business Documents.

Below you will find practical examples to adapt the documents to your wishes. For more complex requirements, see the Creation Process.

Deposit company logo

The company logo is printed on public documents. Follow these steps to add your logo:

  1. In the main view, navigate to the menu item System Configuration.
  2. In the Organization section, click on the sub-item Organizational structure.
  3. On the right side of the tree view, click on the desired organization.
  4. In the action bar of the Organization Editor, click on the Edit Logos action.
  5. Now enter your company logo under Business Document Logo.
Note

A logo in the size of 480 * 80 pixels is recommended so that the representation in the header is sufficient. If this is not possible, you can edit the default headers and footers in the integration project.

General Layout Adjustments

The business documents are generated with so-called liquid snippets. A liquid snippet is a template that renders the data of the underlying business document in FO syntax. When creating the standard documents, care was taken to ensure that the individual components of the document were mapped into separate templates (snippets). In the integration project, you can overwrite individual snippets and thus adjust the layout selectively.

One use case for this is to adjust the headers or footers of the document:

  1. In the Integratiosnprojekt, create the file GlobalSnippets.liquid under documents.
  2. Override the CommonExternalPageHeader snippet according to your requirements.

Example: Output logo on the left side of the header

''' {%- snippet CommonExternalPageHeader %} <fo:table border-width="0.1mm" border-bottom-style="solid" display-align="after"> <fo:table-column column-width="proportional-column-width(3)" /> <fo:table-column column-width="proportional-column-width(2)" /> <fo:table-column column-width="proportional-column-width(4)" /> <fo:table-body> <fo:table-row> <fo:table-cell> <fo:block> <fo:external-graphic max-width="240px" max-height="40px" src="{{ CustomerLogo.BusinessDocumentLogo.UriString | default: 'Images/Logo_Shipping_Pos.jpg' }}" /> </fo:block> </fo:table-cell> <fo:table-cell /> <fo:table-cell> <fo:block> {% render AddressBox, Address: CurrentOwner.Address %} </fo:block> </fo:table-cell> </fo:table-row> </fo:table-body> </fo:table> {% end snippet -%} '''

Adaptation of standard documents

You can customize a standard document by either reworking only parts (snippets) or by redesigning the document from scratch.

Tip

Use the Business Document Playground tool in System Configuration to see the default documents and their structure. In the preview, you can immediately see your adjustments.

Customize snippets

  1. In the Integration Project, under documents, create the file with the technical name of the document you want to customize and add the word snippets to the file name. For example, if you want to customize the shipping slip, name the file ShipmentShippingDeliveryNoteSnippets.liquid.
  2. Now copy only the changed snippets from the Business Document Playground into this file.

You have now adapted parts of the document, all other parts (snippets) are taken from the standard document.

Customize Entire Document

If the desired layout deviates greatly from the standard document, it is recommended to overwrite the document completely. The procedure is similar to the previous point, except that you only have to use the technical name of the standard oculation as the file name. So just ShipmentShippingDeliveryNote.liquid without the addition of snippets.
