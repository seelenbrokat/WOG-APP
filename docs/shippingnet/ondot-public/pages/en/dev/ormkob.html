Ormkob

Ormkob is shippingNET's Object–relational Mapper (ORM).

Features

Match

Match allows you to search for multiple table rows in one operation

Problem

Before storing data, you often need existing values from the database (e.g. the ID). The query can quickly become complicated when batching lists, you would have to:

  1. Filter the search criteria from the list
  2. load the rows for the search criteria from the database
  3. find/match the matching result rows for each list item
  4. Check if there are multiple hits or no hits per list item

Match takes care of these tasks.

Note

If you need more than one search criterion per row (e.g. compound foreign keys), the columns cannot be compared individually, but only in combination. This cannot be expressed in an Ormkob-where because you need temp tables for that. Match makes this requirement possible.

Usage

const myArray: Article[] = [{ Name: 'Sunglasses' }, { Name: 'Raincoat' }]; Articles that are searched for

const matchResult = await ctx.model.Article // the database table in which to search
    .match(
        myArray, // the array that contains the data to be searched for
        (query, array) => query. Name == array. Name, // the expression for the search comparison between the items in the table and the array 
        article => ({ ID: article.ID }), // Projection expression: the data to be loaded from the database for each found article

Additional options
        {
            throwOnMultipleMatches: true // throws an error if the comparison expression returns more than one result for an element of the array
        }
    );

for (const match of matchResult) { // match delivers a MatchResult that returns the found rows from the database for each array element
    const arrayArticle = match. ArrayItem; the article from the array
    const databaseArticle = match. QueryResult; the article from the table (with all columns of the projection printout)

if (databaseArticle) 
        arrayArticle.ID = databaseArticle.ID; Copy the found ID to the array item
}

console.log(myArray); [{ Name: 'Sunglasses', ID: 15 }, { Name: 'Raincoat', ID: 39 }]

Parameters

Name Description
array the array containing the data to be searched
matchtingFunction Filter expression that tells you which criteria list items must be compared and found with the table rows
selection Projection expression: which data to load for the found table rows
options optional additional options
additional options
  • throwOnMultipleMatches: Ensures that the match result returns only one database result for each array element. Throws an error if there are multiple results.
  • throwOnNoMatch: Ensures that there must be at least one database result for each array element. Throws an error if there is no result for an array item.
Tip

The combination of throwOnMultipleMatches and throwOnNoMatch ensures that there is exactly one database result per array element.
