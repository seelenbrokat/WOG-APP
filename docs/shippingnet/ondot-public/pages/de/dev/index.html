Ressourcen für Entwickler und Integratoren

Der Inhalt dieses Abschnittes ist für Entwickler und Integratoren vorgesehen. Lernen Sie hier wie Sie Daten mit shippingNET austauschen bzw. Etiketten und Dokumente anpassen können.

Daten austauschen

Public API

Die Public API von shippingNET ist eine Web-API nach neuestem Stand der Technik in REST-Architektur („Representational State Transfer“). Sie stellt Ihnen eine Schnittstelle für den Import von Artikel, Colli, Aufträgen und Sendungen zur Verfügung. Die Services enthalten auch Methoden, um Daten zu den oben genannten Objekten zu exportieren.

Weitere Informationen finden Sie unter Public API.

Integration Scripting

Falls Sie Daten in einem anderen Format vorliegen haben, können Sie mit Hilfe der Integration Scripts Daten konvertieren und in shippingNET importieren.

Die Scripts bieten Ihnen auch viele Möglichkeiten um Daten zu exportieren.

Weitere Informationen finden Sie unter Integration Scripting.

Dokumente anpassen

shippingNET wird mit einer Vielzahl von Standarddokumenten ausgeliefert. Diese Standarddokumente können Sie in der Systemkonfiguration aktivieren. Siehe auch Geschäftsdokumente erstellen.

Im Anschluss finden Sie praktische Beispiel um die Dokumente an Ihre Wünsche anzupassen. Für komplexere Anforderungen verschaffen Sie sich einen Überblick zum Erstellungsprozess.

Firmenlogo hinterlegen

Auf öffentlichen Dokumenten wird das hinterlegte Firmenlogo angedruckt. Führen Sie folgende Schritte durch, um Ihr Logo zu hinterlegen:

  1. Navigieren Sie in der Hauptansicht zu den Menüpunkt Systemkonfiguration.
  2. Klicken Sie im Bereich Organisation auf den Unterpunkt Aufbauorganisation.
  3. Klicken Sie rechts in der Baumdarstellung auf die gewünschte Organisation.
  4. In der Aktionsleiste des Organisationseditor klicken Sie auf die Aktion Logos bearbeiten.
  5. Hinterlegen Sie nun unter Geschäftsdokument-Logo Ihr Firmenlogo.
Hinweis

Es wird ein Logo in der Größe von 480 * 80 Pixel empfohlen, damit sich die Darstellung in der Kopfzeile ausgeht. Falls das nicht möglich ist, können Sie die Standard Kopf- und Fusszeilen im Integrationsprojekt bearbeiten.

Allgemeine Layoutanpassungen

Die Geschäftsdokumente werden mit sogenannten Liquid-Snippets erzeugt. Ein Liquid Snippet ist eine Vorlage die die Daten des zugrundeliegenden Geschäftsdokumentes in FO-Syntax rendert. Bei der Erstellung der Standarddokumente wurde darauf geachtet, dass die einzelnen Bestandteile des Dokumentes in jeweils separate Vorlagen(Snippets) abgebildet werden. Im Integrationsprojekt können Sie einzelne Snippets überschreiben und damit das Layout punktuell anpassen.

Ein Anwendungsfall dafür ist es die Kopf- bzw. Fusszeilen des Dokumentes anzupassen:

  1. Legen Sie im Integratiosnprojekt unter documents die Datei GlobalSnippets.liquid an.
  2. Überschreiben Sie das Snippet CommonExternalPageHeader nach Ihren Anforderungen.

Beispiel: Logo links in der Kopfzeile ausgeben

{%- snippet CommonExternalPageHeader %}
    <fo:table border-width="0.1mm" border-bottom-style="solid" display-align="after">
        <fo:table-column column-width="proportional-column-width(3)" />
        <fo:table-column column-width="proportional-column-width(2)" />
        <fo:table-column column-width="proportional-column-width(4)" />
        <fo:table-body>
            <fo:table-row>
                <fo:table-cell>
                    <fo:block>
                        <fo:external-graphic max-width="240px" max-height="40px" src="{{ CustomerLogo.BusinessDocumentLogo.UriString | default: 'Images/Logo_Shipping_Pos.jpg' }}" />
                    </fo:block>
                </fo:table-cell>
                <fo:table-cell />
                <fo:table-cell>
                    <fo:block>
                        {% render AddressBox, Address:  CurrentOwner.Address %}
                    </fo:block>
                </fo:table-cell>
            </fo:table-row>
        </fo:table-body>
    </fo:table>
{% endsnippet -%}

Anpassung der Standarddokumente

Sie können ein Standarddokument anpassen indem Sie entweder nur Teile(Snippets) überarbeiten oder das Dokument komplett neu gestalten.

Tipp

Verwenden Sie das Tool Geschäftsdokument Spielplatz in der Systemkonfiguration um die Standarddokumente und deren Aufbau zu sehen. In der Vorschau sehen Sie sofort Ihre Anpassungen.

Snippets anpassen

  1. Legen Sie im Integratiosnprojekt unter documents die Datei mit dem technischen Namen des Dokuments, das Sie anpassen möchten an und ergänzen Sie den Dateinamen mit dem Wort Snippets. Wenn Sie beispielsweise den Sendungs-lieferschein anpassen möchten nennen Sie die Datei ShipmentShippingDeliveryNoteSnippets.liquid.
  2. Kopieren Sie nun nur die geänderten Snippets aus dem Geschäftsdokument Spielplatz in diese Datei.

Sie haben nun Teile des Dokuments angepasst, alle anderen Teile(Snippets) werden vom Standarddokument genommen.

Gesamtes Dokument anpassen

Falls das gewünschte Layout sehr stark vom Standarddokument abweicht, empfiehlt es sich das Dokument komplett zu überschreiben. Die Vorgangsweise ist ähnlich wie im vorherigen Punkt, ausser, dass als Dateiname nur der technische Namen des Standardokuments genommen werden muss. Also nur ShipmentShippingDeliveryNote.liquid ohne dem Zusatz Snippets.
